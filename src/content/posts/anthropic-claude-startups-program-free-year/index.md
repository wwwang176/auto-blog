Anthropic 在美國時間 **2026 年 10 月 6 日**（台灣時間 10 月 7 日）宣布[擴大「Claude Startups」新創計畫](https://claude.com/resources/articles/were-expanding-the-claude-startups-program-to-help-founders-build)。簡單說：**審核通過的新創公司，可以免費用一年 Claude Team 方案，另外拿到一次性 1,000 美元的 API 額度**，還有合作夥伴的工具折扣和 Anthropic 團隊的線上諮詢時段。

要注意，依 Anthropic 官方頁面，免費一年的是給團隊用的 **Claude Team** 方案，不是 Enterprise 方案。

## 新創可以拿到什麼

依 [Claude Startups 官方頁面](https://claude.com/programs/startups)的說明：

| 項目 | 內容 |
|---|---|
| Claude Team 一年免費 | 最多 **5 個 Premium 席位**，限**第一次使用 Team 方案**的組織 |
| API 額度 | 一次性 **1,000 美元**，審核通過後就能領，**發放後 6 個月到期** |
| Claude Startup Stack | 合作廠商提供的折扣與額度，官方估計總值最高約 **4.5 萬美元** |
| 其他 | 較高的 API 使用上限、每兩週一次的 Anthropic Applied AI 團隊線上諮詢、創辦人活動與黑客松 |

Anthropic 自己估算，Team 加上 API 額度的價值最高約 **7,000 美元**：5 個 Premium 席位按年繳每席每月 100 美元，一年是 6,000 美元，再加 1,000 美元額度。實際價值看你用幾個、哪一種席位而定。

幾個細節要注意：

- **已經在用 Team 方案的組織不適用**這次的免費一年。
- API 額度只能用在 Anthropic 自家的 Claude API（透過 Claude Console），**不能用在 AWS Bedrock、Google Vertex AI 等第三方平台**。
- Startup Stack 的優惠由各家合作廠商提供，例如 ElevenLabs、ClickHouse、Gamma 等，條件依各家規定，不一定每一項都能拿到或合併使用。
- 如果新創背後的創投在 Anthropic 的合作名單內，還可以透過創投另外申請最高 **10 萬美元**的 API 額度。

## 誰可以申請

官方 FAQ 列出的條件：

1. **成立 5 年內，或最近 2 年內有拿到資金**的新創。
2. 不一定要有創投投資，自己出資（bootstrapped）、種子輪前的公司也能申請。
3. 需要一個 **Claude Console 帳號**、一個**跟公司網站同網域的公司信箱**，以及一段簡短的產品說明。

申請方式是登入 Claude Console 填表。官方說大部分申請幾分鐘內就有結果，其餘轉人工審查，通常要 2 到 3 個工作天。根據[計畫條款](https://www.anthropic.com/startup-program-official-terms)，Anthropic 審核時會參考營運進展、投資與資金、Claude 的整合與使用情況等，最後由 Anthropic 決定。

## 台灣讀者看這裡

- **台灣新創能不能申請**：[計畫條款](https://www.anthropic.com/startup-program-official-terms)排除的地區是白俄羅斯、中國、古巴、伊朗、緬甸、北韓、俄羅斯、蘇丹、敘利亞，以及克里米亞等地，**名單裡沒有台灣**；台灣也列在 Anthropic 的[支援地區清單](https://www.anthropic.com/supported-countries)。所以台灣新創可以送件，但能不能通過還是看審核。條款也寫明，如果公司打算把服務提供給上述地區的使用者，同樣不符資格。
- **金額都是美元**：以臺灣銀行 [10 月 8 日 16:00 的美元即期賣出牌告](https://rate.bot.com.tw/xrt/quote/2026-10-08/USD)（31.95）概算，1,000 美元 API 額度約 **NT$3.2 萬**；一年 5 個 Premium 席位的 6,000 美元約 **NT$19.2 萬**；官方估的總值 7,000 美元約 **NT$22.4 萬**。
- **Team 平常要多少錢**：依 [Claude 定價頁](https://claude.com/pricing)，Team 的 Premium 席位按年繳每席每月 100 美元（約 NT$3,195），Standard 席位按年繳每席每月 20 美元（約 NT$639）。Anthropic 最近的模型與價格調整，可以參考本站的〈[Claude Haiku 5.5 登場](/posts/claude-haiku-5-5/)〉。

## 小編觀點

對台灣的小型新創來說，這個計畫的門檻不高：不需要創投背書，成立 5 年內就能送件，台灣也不在排除名單裡。真正值錢的是一年 5 個 Premium 席位，約 NT$19 萬，是實在的補貼；1,000 美元 API 額度則比較像試用金，6 個月內用完，適合拿來做原型和初步測試，不夠撐起正式上線的產品。

要注意兩點：第一，額度只能用在 Anthropic 自家 API，習慣透過 AWS 或 Google Cloud 呼叫 Claude 的團隊得另外開帳號；第二，免費一年是為了讓團隊把工作流程建在 Claude 上，期滿後的成本要先算清楚，別因為免費就把整套工具綁死。正在評估 AI 工具的新創值得申請，已經是 Team 用戶的就拿不到這次的免費一年。
